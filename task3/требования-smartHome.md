# Требование к интеграции с устройствами умного дома

## Требования к безопасности
1) Биометрия пользователей и персональные данные лежат в отдельной базе в зашифрованном виде
2) Ключи шифрования лежат в Vault 
3) Применяется ротация ключей
4) Действия клиентов с устройствами умного дома подлежат аудиту
5) Доступ к vault имеет только администратор (devops)

## Протоколы аутентификации и авторизации
1) HTTPS (TLS 1.3) для регистрации устройств и управления ими
2) WSS (TLS 1.3) для стриминга видео с домофона

## Взаимодействие с внешней платформой
1) Пользователь добавляет новое устройство через мобильное приложение для жильцов
2) При регистрации можно добавлять биометрию также через приложение для жильцов, биометрия хранится во внутренних бд в зашифрованном виде
3) При проверке устройство умного дома запрашивает по https валидную биометрию и проверяет ее. Механизм проверки госномеров авто работает аналогично.
